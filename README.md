# StickerSmash

A small mobile app built while following [Expo's official tutorial](https://docs.expo.dev/tutorial/introduction/) to learn **React Native** and **Expo Router**. My first Expo project.

Pick a photo, add emoji stickers on top, drag them around, and double-tap to resize.

## Built with

- [Expo](https://expo.dev/) (SDK 54) + [Expo Router](https://docs.expo.dev/router/introduction/) (file-based navigation)
- React Native + TypeScript
- `expo-image-picker`, `react-native-gesture-handler`, `react-native-reanimated`

## Run it locally

```bash
npm install
npx expo start
```

Then open the app in [Expo Go](https://expo.dev/go) or an iOS/Android simulator.
